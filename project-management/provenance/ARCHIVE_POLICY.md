# Project and Archive Policy

The active project and `local-archive` are complementary local
collections.

- Active project directories contain curated research code,
  evidence, configurations, and lightweight reproducibility files.
- `local-archive` contains server snapshots, external datasets,
  environment payloads, historical backups, and archive-only data.
- Exact duplicates previously found across the boundary were
  removed from the archive side and retained in the active project.
- `obsolete-assets` retains non-paper implementations and
  superseded records outside Git.
- Manuscripts remain local-only and outside the public repository.

No local archive path is required for public repository checkout or
lightweight source validation.
