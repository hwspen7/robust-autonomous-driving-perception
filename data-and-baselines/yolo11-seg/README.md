# YOLO11 Segmentation Auxiliary Evidence

## Role

This directory preserves the YOLO11 segmentation experiment used during
the exploratory diagnostic stage of the project.

It is retained as auxiliary research evidence. It is not part of the
canonical object-detection comparison and must not be presented as if it
were evaluated under the same final protocol as YOLO11m, D-FINE-M,
projected P2, Uniform, or Risk training.

## Preserved evidence

- Prediction metadata
- Image-level summary
- Raw prediction payload
- Deterministic visualizations

## Canonical implementation

The single retained implementation is:

`source-code/utilities/diagnostics/run_yolo11seg_diagnostic.py`

No second script copy is stored in this evidence directory.
